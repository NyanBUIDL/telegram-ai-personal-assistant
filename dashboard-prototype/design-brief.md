# Telegram AI Admin — Prototype brief

## Visual thesis

A retro operations desk rendered as a disciplined neo-brutalist control surface: paper-beige canvas, compressed black typography, thick rules, hard offset shadows, and loud teal, magenta, and yellow status colors.

## Content plan

1. Persistent workspace navigation and owner/runtime identity.
2. Operational overview with KPIs, AI routing activity, service health, pending actions, and audit events.
3. Focused workspaces for Telegram groups, PendingAction review, knowledge corpus, and runtime health.
4. Confirmation and feedback surfaces for sensitive actions.

## Interaction thesis

- Fast view switching and time-range changes should feel like operating a physical console.
- Sensitive actions open a high-contrast confirmation layer before changing state.
- Hover, press, toast, sync, responsive navigation, and AUTO-mode states use short, tactile motion with always-visible keyboard focus.
